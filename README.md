# Vibe Campus App

A university news, event tracking, and campus community application developed for the **SE 2001 - Software Engineering Concepts** course at Muğla Sıtkı Koçman University.

## Core Modules
- **Pulse:** Real-time university news, announcements, and campus updates.
- **Plans:** Upcoming campus events, club activities, and academic schedules.
- **Lost & Found:** A dedicated board for reporting and finding lost items across campus.
- **Authentication:** Secure student login and profile management.
